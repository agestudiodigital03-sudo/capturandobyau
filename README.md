# Capturando by Yau

Sitio web estático. Versión con fotos reales, recomendaciones, video, álbum de regalo y sección de equipo ilustrativa.

## Archivos

- index.html: contenido y estructura.
- styles.css: diseño y tipografías.
- script.js: navegación, galerías y preparación del mensaje para Instagram.
- assets/: logo, fotos, ilustración del equipo, video y su portada.

## Para subirlo a tu repositorio

1. Descomprime el ZIP.
2. Sube index.html, styles.css, script.js y la carpeta assets a la raíz del repositorio, conservando sus nombres.
3. Publica la raíz como sitio estático en el alojamiento que elijas. No se requiere instalación ni comando de compilación.

Git guarda los archivos; para que la página se vea en internet también necesitas habilitar un servicio de publicación.

## Para editar

Abre la carpeta en VS Code. Puedes revisar index.html en el navegador o ejecutar `python -m http.server 8000` desde la carpeta y abrir http://localhost:8000.

## Detalles pendientes

- Los ejemplos de iPhone, estabilizador, micrófono y luz son provisionales. Sustituirlos por el equipo confirmado de Yau.
- Confirmar la cantidad de fotos del álbum de cada paquete.
- El formulario prepara el mensaje para copiarlo y enviarlo por Instagram; no envía ni guarda consultas en un servidor.
